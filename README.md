# 🏏 Cricket Buddy Fielder

An interactive web-based tool for cricket captains to plan their fielding restrictions and strategies.

## ✨ Features
* **Interactive Field:** Drag the Wicket Keeper and Bowler to set your line.
* **Smart Selection:** Toggle between 30+ standard fielding positions.
* **Format Presets:** Quick-set buttons for Test Matches and ODI Powerplays.
* **LHB/RHB Toggle:** Automatically mirrors the field for Left-Handed Batters.
* **Position Tracker:** Live table showing currently selected fielders.
